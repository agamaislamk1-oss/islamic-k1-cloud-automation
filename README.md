## Jalur 1 (Paling Direkomendasikan): Server Cloud 24 Jam Non-Stop Hugging Face (100% Gratis, Tanpa Kartu Kredit)

Hugging Face menyediakan server **Docker CPU Basic (2 vCPU, 16 GB RAM)** yang menyala **24 jam non-stop meskipun komputer Anda dimatikan**, 100% gratis selamanya tanpa kartu kredit.

### Langkah Aktivasi Sekali Saja (2 Menit):
1. Buka **https://huggingface.co/join** dan buat akun gratis (lalu verifikasi email Anda).
2. Buka **https://huggingface.co/settings/tokens** -> klik **Create new token**:
   - Pilih tab **Write** (atau centang izin Write).
   - Beri nama `IslamicK1` -> klik **Create token** -> **Copy** token yang diawali `hf_...` tersebut.
3. Buka **Windows PowerShell** di komputer Anda, lalu jalankan 2 baris perintah ini (ganti `hf_TOKEN_ANDA` dengan token tadi):
   ```powershell
   cd "C:\Users\thinkpad\.gemini\antigravity\scratch\islamic-k1-automation"
   powershell -ExecutionPolicy Bypass -File .\Deploy_Cloud_24Jam_Gratis_HuggingFace.ps1 -HuggingFaceToken "hf_TOKEN_ANDA"
   ```
4. Selesai! Script akan otomatis membuat server Cloud 24 jam, memasang `token_drive.json` & `token_youtube.json`, dan menyalakan robot pemantau 24 jam penuh.
